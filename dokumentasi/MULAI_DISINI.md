## 📋 **LANGKAH CEPAT UNTUK ANDA**

### **STEP 1: Install Python** ⏱️ 10 menit

**Cara termudah:**
1. Buka: https://www.python.org/downloads/
2. Download Python 3.12
3. Jalankan installer
4. ⚠️ **PENTING:** Centang **"Add Python to PATH"**
5. Klik "Install Now"

**Atau baca panduan lengkap:** `PANDUAN_INSTALL_PYTHON.md`

---

### **STEP 2: Install Dependencies** ⏱️ 5 menit

Buka Command Prompt di folder backend:

```bash
cd backend
pip install -r requirements.txt
```

Tunggu sampai selesai.

---

### **STEP 3: Jalankan Backend** ⏱️ 1 menit

```bash
python main.py
```

**Atau double-click file:** `backend\start_backend.bat`

---

### **STEP 4: Test Sistem** ⏱️ 2 menit

1. **Frontend:** http://localhost:3000/
2. **Backend:** http://localhost:8000/
3. **API Docs:** http://localhost:8000/docs

Upload `backend\sample_data.csv` via Swagger UI untuk test ML.

## ❓ **TROUBLESHOOTING CEPAT**

### **Q: Python not found?**
**A:** Restart Command Prompt setelah install Python

### **Q: Module not found?**
**A:** Jalankan: `pip install -r requirements.txt`

### **Q: Port already in use?**
**A:** Tutup program yang pakai port 8000 atau 3000
